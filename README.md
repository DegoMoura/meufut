# MeuFut

App web (HTML/CSS/JS em arquivo único) para organizar peladas de futebol: montagem de times, controle de jogadores e placar.

Site oficial: [meufut.app](https://meufut.app) · Contato: contato@meufut.app

## Estrutura

```
index.html   # aplicativo completo (HTML + JS inline)
style.css    # estilos do app
CNAME        # dominio customizado do GitHub Pages (meufut.app)
```

## Como rodar

Abra `index.html` diretamente no navegador, ou sirva localmente:

```bash
python3 -m http.server 8000
# acesse http://localhost:8000/
```

## Deploy

Publicado via GitHub Pages a partir da raiz da branch `main`. O domínio meufut.app aponta pra cá através do arquivo `CNAME`.
